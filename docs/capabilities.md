# 能力与规则口径

全部为合成演练，不用于真实设计。系统把钻进叙述、取样登记、实验报告、设计选用说明处理为
**只追加的事件流**，层位事实、有限观察、未确认主张、保守假设与缺样区严格分账，每个结论都可回查
到原文编号与原句。

## 1. 录入与解析（`parser.py` / `ingest.py`）

- 深度以孔口向下为正，区间左闭右开；标高 = 孔口标高 − 深度，各孔以本孔孔口为基准。
- 支持中文、单位简写（`m/M/米/公尺`）与省略句；省略句只继承**同一记录内**已确认的孔号/样号，
  绝不借用邻孔或页码。
- “继续两米”不在解析阶段补造深度，而由台账挂接**同孔上次确认进尺**；找不到同孔锚点直接拒绝。
- 语义不明的口语（如“六米上没有”“六米以上未取到样”）进入未确认主张，不生成任何深度/层位事实。
- 转述送样（“六号样送实验室”）不绑定登记样号，禁止凭邻号猜同袋。

## 2. 证据状态分账（`model.py` / `geology.py`）

| 状态 | 含义 | 禁止的解释 |
| --- | --- | --- |
| `measured` | 有出处的实测/定位事实 | —— |
| `not_recovered` | 取样筒空、未取到样（点状） | 解释为“无此层/无异常” |
| `observation_limited` | 观察时段内未见，带时段终点 | 外推为永久无水 |
| `unconfirmed` | 语义不明、地质员未确认 | 当作独立观察 |
| `assumption` | 带补查触发条件的保守假设 | 标为实测 |
| `derived` / `corrected` | 基准推算或更正后的归属 | 改写原始深度 |

缺样区（`unsampled`）只表达“没有实测证据”，不能当均一硬层或无异常。

## 3. 样号与基准更正（`ledger.py`）

- **样号重编号**必须有封签、接收单等同袋证据；证据不足或旧号无登记时，更正被拒绝并留痕。
  重编号只改实验归属，深度不变，旧号进入别名、仍可回查。
- **基准更正**产生新的孔口基准版本（D0→D1…），只改变推算标高；原文深度与已完施工记录不移动。
  他孔“基准不变”的说明不会误触发更正事件。
- 两类更正同时发生时，`construction.correction_impact()` 给出受影响孔、样号映射、分区、
  待重核选用、未完施工段与不可变的已完施工登记。

## 4. 参数选用（`parameters.py`）

- 实验值不是自动可用参数。混合样未分层试验的强度仅适用于该混合区间与对应试验类型，
  禁止用平均强度覆盖所有深度。
- 证据区间与设计部位不重叠时，明确标注为无实测支撑的外推并列出前提。
- 引用邻孔样品直接拒绝借用，该分区转为无有效引用、待补查，不抄邻孔强度填空。
- 缺样区只能暂用带触发条件的保守假设；补样出现软夹层等推翻前提时，关联假设失效、
  选用说明与施工允许范围进入 `requires_review`；无关层/无关孔的既有依据保持有效。
- 已签认选用若缺少对应试验类型实测值，签认暂不生效并自动转重核。

## 5. 施工交接（`construction.py`）

- 交接区间三类：可作业、停待补查、已完成，同分区内互不重叠，附监测条件与依据。
- 软夹层、未回收点、缺样区、进入重核的选用都产生停待补查区间。
- 实际开挖登记固定在登记时的基准版本，同时给出当时与当前基准的等效深度；
  已完施工不会因基准更正被移动成另一深度记录。

## 6. 可追溯与事件溯源（`trace.py` / `ledger.py`）

- 所有状态变化都是只追加事件，保存为 JSONL 后可完整重放出相同快照（测试固化该等价性）。
- 支持按样号（含旧编号别名）、深度、标高、分区回查；待查清单汇总未确认主张、未回收点、
  转述送样、假设触发、重核选用与被拒绝的更正。

## 7. 运行方式

```sh
# 全量处理，输出 JSON 台账、结构化报告与 Markdown 交接报告
python3 -I run_demo.py data/case.json --outdir out

# 同时导出只追加事件流
python3 -I run_demo.py data/case.json --outdir out --events out/events.jsonl

# 单点回查
python3 -I run_demo.py data/case.json --trace-sample S60
python3 -I run_demo.py data/case.json --trace-depth K6 6.4
python3 -I run_demo.py data/case.json --trace-elevation K6 94.1

# 测试（含原始资料完整性检查与全部业务规则）
python3 -I -m unittest discover -s tests -v
```
