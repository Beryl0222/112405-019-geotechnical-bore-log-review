# 地质钻探日志的层位归属与风险边界

项目保存用于本地业务联调的合成原始文本、对象登记及已有办理记录。文字包含尚未确认的主张，不能直接当作业务结论。资料口径见 [资料口径](docs/materials.md)。

`data/case.json` 是一份可追加原文的资料包；`docs` 记录输入含义，`tests` 检查资料完整性。当前可运行入口仅用于读取和检查资料，尚不提供业务办理功能。

使用 Python 3.11 或更新版本，无第三方运行依赖。读取资料：

```sh
python3 -m json.tool data/case.json
```

运行资料检查：

```sh
python3 -m unittest discover -s tests -v
```

这项检查验证资料可读取、编号与引用有效；它不验证尚未提供的业务能力。
